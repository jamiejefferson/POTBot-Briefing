# Phase D: the murder board

The adversarial rehearsal — murder boards, PMQs prep, debate stand-ins, moots
all in one. Two distinct jobs: surface the gap between recognition and recall
while being wrong is still cheap, and *stress-inoculate* so the real room
feels easier than the rehearsal. Run it only after a passed teach-back.

## Setting it up

**Build the personas from the triage audience model.** Generic skeptics ask
generic questions; real preparation is specific. For each named person (or
role) in the room, note: what they care about, what they're skeptical of, what
they'll have read before, and their questioning style (interrupter?
detail-burrower? big-picture challenger? silent-then-lethal?). If the user
knows these people, spend one minute harvesting: "How does [name] usually push
back?" Merge what they say into the personas.

**Teach the answer discipline before round one** (60 seconds, once):

1. Pause before answering — a beat is command, not weakness.
2. Answer the question asked, first: yes / no / it depends / a number.
3. Then bridge to a pillar — one bridge per answer; serial bridging reads as
   evasion.
4. Never guess. At the perimeter, deploy the deferral or the universal exit
   ("I don't know — I'll come back to you by [when]").
5. Stop talking when the answer is done. Every unforced word is new attack
   surface.

**Announce the format:** who you'll be, roughly how long, that you'll be
harder than the real room, and that you'll break role for feedback between
rounds — never mid-answer.

## Voice protocol

Spoken rehearsal is categorically better than typed: speaking is the
performance modality, it prevents composing/editing answers, and the stumble
happens where it's informative.

- **If the user's surface supports voice conversation** (Claude mobile or
  desktop voice mode): recommend switching to it for this phase and run the
  murder board as a spoken session. Keep your questions short and
  interruptible; let silences sit — silence under pressure is part of what's
  being trained.
- **If text-only:** approximate the pressure. Ask the user to speak each
  answer aloud *before* typing only its essence (one or two lines, no
  polishing — "type what you actually said, not what you wish you'd said").
  Impose a short clock ("answer within about 30 seconds — first thought,
  committed"). One question at a time, no take-backs once sent.
- Either way, tell the user why: the real room is spoken, and rehearsing in
  the performance modality is what makes the inoculation take.

## The question taxonomy

Draw each round from across these types — a board that only asks "why"
questions trains only one muscle. Enter the material in **random order**
(never the deck's sequence): command must not depend on the running order,
because real questioners don't follow the outline.

| Type | Example shape | It trains |
|---|---|---|
| Provenance attack | "Where does that number come from?" | One-hop sourcing |
| Why-chain | "Why?" … "And why is *that* true?" (2–3 deep) | Reasoning below the pillars |
| Rejected alternative | "Did you consider X? Why isn't that better?" | Decision log command |
| Assumption flip | "What if [assumption] is wrong?" | Knowing what the case rests on |
| Coverage challenge | "The brief asked for Y — where is it?" | Coverage map (incl. flagged gaps) |
| Compound question | Two questions in one, second one loaded | Decomposing before answering |
| Interruption | Cut off mid-answer with a new angle | Composure; re-entry from anywhere |
| Scope bait | Question just outside the perimeter, asked confidently | Deferral without flinching |
| The feared question | The one the user said they dread | Retiring the nightmare in private |
| Confidence probe | "How sure are you? Would you bet on it?" | Calibrated language under pressure |
| Sanity check | "Does that number even make sense? It sounds high." | Anchors; recovering a slipped fact |
| The softball trap | Friendly question inviting an overclaim | Discipline when it feels safe |

Be harder than the real room, but keep it winnable: escalate across rounds
rather than opening at maximum hostility, and land at least a few questions
the user handles cleanly — inoculation requires surviving, not drowning.

## Between rounds: feedback

Break role explicitly ("Okay — out of role"). Score against the rubric,
openly, with one concrete moment cited per line:

| Dimension | What you're judging |
|---|---|
| Content command | Answers from understanding vs recitation; survives the why-chain |
| Provenance | Sources load-bearing claims without notes |
| Answer discipline | Pause; question-first; one bridge; stops talking |
| Composure | Recovery from interruption; pace under compound questions |
| Scope control | Defers cleanly at the perimeter; no volunteering |
| Honesty at the edge | Deploys "I'll come back to you" instead of bluffing; never upgrades assessed→known |

Then name: what held, what cracked, and which answers were **borrowed rather
than owned** (fluent wording that collapsed one "why" later — the tell is a
recited phrase followed by silence). Cracked spots get a two-minute repair
(re-brief that point, have them re-say it their way), then re-attack the same
spot from a *different* question type before moving on.

Praise correct honesty loudly: a clean "I don't know — I'll come back to you"
at the perimeter is a scored win, not a dodge.

## Level 3 extras

- **Full-round repeats** until a clean pass: no borrowed answers, discipline
  holding under interruption, edges handled honestly.
- **The premortem** (10 minutes, before the final round): "It's the day after.
  The presentation failed badly. Write down — quickly, unfiltered — the three
  most likely reasons why." You contribute failure modes too, including ones
  outside the content (room dynamics, a blindside topic, tech). Each
  plausible failure mode gets a mitigation, and content-shaped ones feed the
  defensive annex before the final round.
- **The shuffled entry drill** (John Roberts' index cards): name a pillar or
  annex topic at random; the user delivers it standalone in under a minute,
  linking it back to the top-line claim. Repeat 4–5 draws. This is what makes
  command independent of sequence.
- **A human second questioner:** if a colleague can join the final round,
  brief them with three questions from the annex and one instruction ("follow
  up on anything vague"). A second human voice is the strongest available
  approximation of the real room; offer to draft the colleague's one-page
  facilitator sheet.

## Exit criteria

The murder board is done when: the why-chain holds two levels below every
pillar; load-bearing facts survive the sanity check; the perimeter held under
scope bait; the feared question has been answered acceptably at least twice;
and the user's answers have stopped shrinking toward recitation and started
sounding like *them*. Then proceed to Phase E — sign-off while the earned
confidence is fresh.
